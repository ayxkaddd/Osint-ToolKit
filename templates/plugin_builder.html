1Paste an example optional, but the quickest way

Services explain their API with example requests - usually a line starting with curl. Copy one from the service's API documentation and paste it here: the form below is filled in for you, and your API key is found and kept safe.

Where do I find one?
  • In the service's API documentation (search the web for "service name API"), look for an example with "curl".
  • Or from your browser: open the site, press F12 → Network, do a search on the site, right-click the request → Copy → Copy as cURL.
